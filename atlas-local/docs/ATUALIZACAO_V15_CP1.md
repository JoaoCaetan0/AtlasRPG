# V15 — Checkpoint 1: enquadramento
Encerre o Atlas, faça backup de data/ e extraia este ZIP na pasta que contém atlas-local, substituindo os arquivos do programa. Preserve data/ e campaign/. Inicie o servidor dessa pasta e pressione Ctrl+F5 em todos os navegadores.
O pacote contém o programa completo atualizado, tokens e instruções, mas não repete mapas. É atualização para instalação existente.
Ao abrir mapa, a imagem é enquadrada nos limites de largura e altura. Zoom é manual e relativo a essa visão completa; 100% significa enquadrado. Ver mapa inteiro restaura a visão completa. Alterações de combate não reposicionam o zoom.
Esta entrega cobre CP0 e CP1. Busca de mapas/condições, horários compartilhando estado, mortos, novos ícones, desenhos e lótus permanecem no plano das próximas etapas. Leia PLANO_V15.md para retomada.
